# Syntecxhub Student Performance Analysis

## 📌 Project Overview

Student Performance Analysis is a data analysis project developed as part of the Syntecxhub Data Analysis Internship.

The project analyzes student academic performance using marks, attendance, study hours, and other student-related factors. The analysis is performed using Python, SQL, and Power BI.

## 🎯 Objectives

- Analyze subject-wise and overall student performance
- Study the relationship between attendance and marks
- Analyze the effect of study hours on performance
- Compare performance across different classes and groups
- Analyze pass/fail and grade distributions
- Identify important performance patterns
- Create visualizations for better understanding of the data

## 🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- MySQL
- Power BI
- Microsoft Excel/CSV
